Esta página apenas consulta publicações. Nenhuma atualização é executada aqui.

Como atualizar

Siga somente o método identificado. A publicação de uma versão não comprova compatibilidade.

Faça backup antes de atualizar.

O backup da interface cobre o banco de dados, mas não inclui uploads, anexos, fotos, logos nem o arquivo de configuração. Abrir Backups

A atualização não garante restauração ou rollback automático. Preserve banco, WAL, uploads, configuração, chaves e o pacote anterior.

{{if eq $method "release"}}

Release / systemd

Execute no host que roda o serviço systemd do ContaBase. O comando global usa o canal salvo e recusa downgrade.

{{if $showCommand}}
sudo contabase-update

{{if eq $status "newer"}}O comando usa o canal salvo e recusa downgrade.{{else}}Você já está na versão publicada; o comando não fará downgrade.{{end}}

{{else}}

{{$noCommandHint}}

{{end}}
  • Execute no host, não dentro de um contêiner.
  • Confirme o serviço e o healthcheck depois da atualização.
  • Não há restauração ou rollback automático.

Conferir depois

systemctl status contabase curl '{{$healthcheckURL}}'

A URL do healthcheck vem de APP_BASE_URL: use 127.0.0.1/localhost no modo Local, o IP ou domínio da LAN, ou o domínio HTTPS do proxy.

{{else if eq $method "source"}}

Source legado

Execute no host, a partir do checkout Git persistente. O checkout precisa estar em uma branch com upstream; HEAD destacado não é aceito.

{{if $showCommand}}
sudo contabase-update

{{if eq $status "newer"}}O comando usa o canal salvo e recusa downgrade.{{else}}Você já está na versão publicada; o comando não fará downgrade.{{end}}

{{else}}

{{$noCommandHint}}

{{end}}
  • Confirme o checkout e a branch: git status -sb e git branch -vv.
  • Não use este procedimento em instalações Source Bootstrap.
  • O updater Source legado mantém o comportamento existente; a publicação não comprova suporte.

Conferir depois

systemctl status contabase curl '{{$healthcheckURL}}'

A URL do healthcheck vem de APP_BASE_URL: use 127.0.0.1/localhost no modo Local, o IP ou domínio da LAN, ou o domínio HTTPS do proxy.

{{else if eq $method "docker"}}

Docker Compose do instalador

Execute no host que hospeda o contêiner. O comando não existe dentro do contêiner e não deve ser executado nele.

{{if $showCommand}}
contabase-update

{{if eq $status "newer"}}O comando usa o checkout e o canal registrados pelo instalador.{{else}}Você já está na versão publicada; o comando não fará downgrade.{{end}}

{{else}}

{{$noCommandHint}}

{{end}}
  • O comando usa o checkout e o estado registrados pelo instalador.
  • Não use este caminho para Compose manual sem estado; nesse caso, siga a atualização manual do Compose.
  • Confirme o contêiner e os logs depois da atualização.

Conferir depois

docker compose ps docker compose logs --tail 100 contabase curl '{{$healthcheckURL}}'

A URL do healthcheck vem de APP_BASE_URL: use 127.0.0.1/localhost no modo Local, o IP ou domínio da LAN, ou o domínio HTTPS do proxy.

{{else if eq $method "docker-image"}}

Docker por imagem/digest Em validação

Este caminho ainda está em homologação e não está declarado pronto para produção. Não há comando recomendado nesta página.

  • Não trate a versão publicada como autorização para atualizar.
  • Preserve banco, WAL, uploads, configuração e chaves; o consumidor instalado pode falhar fechado.
  • Consulte o administrador e o guia da release antes de qualquer tentativa.
{{else if eq $method "source-bootstrap"}}

Source Bootstrap Não suportada

Este método é experimental e não possui atualização suportada.

  • Não execute contabase-update, cb-update nem update-contabase-source.sh.
  • Para novas instalações VPS/LXC, prefira o binário da Release.
  • Não trate essa instalação como produção com dados reais.
{{else}}

Método não identificado

O ContaBase não conseguiu ler o estado canônico desta instalação. Não copie comandos de atualização antes de confirmar o método no host.

sudo grep '^CONTABASE_INSTALL_METHOD=' /etc/contabase/install-state.env

Em Docker, execute no host; o contêiner não lê esse arquivo por padrão. Se o arquivo não existir, a instalação pode ser um Compose manual ou um build local.

Docker Compose do instalador

Confirme que a instalação foi criada pelo instalador Docker e possui install-state.env. Execute no host.

contabase-update
Docker Compose manual (GHCR)

Somente para Compose manual, sem install-state.env e sem contabase-update. Use uma imagem com tag ou digest fixo; não use latest.

docker compose pull
docker compose up -d
Release / systemd

Se o estado indicar release, execute no host que roda o serviço systemd.

sudo contabase-update
Source legado

Se o estado indicar source, confirme o checkout persistente, a branch e o upstream antes de executar.

sudo contabase-update

Se o estado indicar docker-image, o caminho está em validação e não há comando recomendado. Se indicar source-bootstrap, não há atualização suportada.
