# ContaBase v0.1.0-beta.6 - Beta publica controlada

> **Status:** Em preparacao; ainda nao publicada
>
> **Estagio:** Beta publica controlada, nao stable

## Principais mudancas desde v0.1.0-beta.5

### Adicionado
- **Relatorios — Contabilidade empresarial:** novo relatorio contabil para workspaces Business, com resumo, grupos de macro, saldos de contas e exportacoes CSV, PDF e ZIP.
- **Relatorios — Contrato de macros:** contratacao centralizada para classificar as linhas do relatorio por macro e padronizar os agrupamentos.
- **Business — base de validacao:** novo seed de receita financeira empresarial e fixture de smoke para validar o relatorio contabil.

### Alterado
- **Interface — Dashboard:** card carousel redesenhado com controles em grid e remocao do painel de resumo.
- **Interface — Estilo e navegacao:** Tailwind atualizado para v4.3.0, estilos refinados e navegacao responsiva polida.
- **Interface — Mobile settings:** espacamento normalizado nas telas de configuracoes.
- **Relatorios — cores semanticas:** saldos passaram a usar cores semanticas nos resumos e exportacoes.

### Corrigido
- **Business — categorias canônicas:** reparo das categorias canônicas usadas pelo workspace Business.
- **CSS — build:** remocao da camada de propriedades do Tailwind do `style.css`.
- **Relatorios — acao de PDF:** exposicao da acao de PDF do relatorio contabil ajustada.

## Contrato de instalacao

### Canal stable

```bash
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/install.sh
bash /tmp/contabase-install.sh
```

Enquanto nao houver stable publicada, este fluxo deve abortar com mensagem clara.

### Canal beta

```bash
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/beta/install.sh
bash /tmp/contabase-install.sh
```

Este fluxo instala a versao apontada por `public/channels/beta.json`.

### Versao fixa (Docker)

```bash
export CONTABASE_VERSION=v0.1.0-beta.6
export CONTABASE_DATA_DIR=/opt/contabase/data
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/beta/install.sh
bash /tmp/contabase-install.sh
```

### Versao fixa (LXC/VPS - binario)

```bash
export CONTABASE_VERSION=v0.1.0-beta.6
export CONTABASE_INSTALL_DIR=/opt/contabase
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/beta/install.sh
bash /tmp/contabase-install.sh
```

### Imagem Docker

```bash
docker pull ghcr.io/contabase-app/contabase:v0.1.0-beta.6
```

### Atualizacao

```bash
export CONTABASE_VERSION=v0.1.0-beta.6
cd /opt/contabase && bash scripts/update-contabase-docker.sh
```

## Notas tecnicas

- **Relatorio contabil:** a visao do Business agora classifica linhas por macro e expõe totais e saldos em CSV, PDF e ZIP.
- **Categoria canônica:** as categorias do Business foram reparadas para manter a leitura consistente do relatório.
- **UI:** dashboard, navegacao e configuracoes mobile receberam polimento visual e ajustes de espacamento.
- **Tailwind:** a base de estilos foi atualizada para v4.3.0 e a camada de propriedades foi removida do `style.css`.

## Limitacoes conhecidas

- Stable ainda nao publicada. A versao recomendada e a ultima beta.
- Instalacao publica aponta para `get-contabase.pages.dev`. O dominio `get.contabase.net` ainda nao esta ativo.
- Backup antes de atualizar ambientes com dados reais continua obrigatorio.
