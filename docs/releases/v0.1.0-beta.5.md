# ContaBase v0.1.0-beta.5 - Beta publica controlada

> **Status:** Em preparacao; ainda nao publicada
>
> **Estagio:** Beta publica controlada, nao stable

## Principais mudancas desde v0.1.0-beta.4

### Adicionado
- **Relatorios — Fluxo de Caixa:** nova estrutura com submodos Realizado e Previsao. Realizado considera apenas dinheiro liquidado por data efetiva, incluindo pagamentos de fatura como saida e excluindo pendentes, compras de cartao e transferencias internas do resultado. Previsao combina realizado e pendente por vencimento, inclui faturas abertas/fechadas pelo saldo pendente, exibe janela movel de mes selecionado + 12 meses e apresenta Saldo Projetado.
- **Relatorios — Extrato:** visao de movimentos confirmados e resumo diario, com receitas, despesas, transferencias e pagamentos de fatura ja realizados. Transferencias aparecem como entrada/saida por conta, sem distorcer o resultado consolidado.
- **Relatorios — Exportacoes:** CSV e PDF para Competencia/DRE, Fluxo de Caixa Realizado/Previsao e Extrato. PDFs usam identidade visual do workspace, fonte TrueType embutida (Go Regular), acentuacao corrigida, paginacao revisada e tabelas com largura proporcional.

### Alterado
- **Interface — Lancamento:** novo lancamento nao pre-seleciona mais a primeira categoria de despesa. Placeholder inicial e "Selecione uma categoria".
- **Interface — Lancamento:** seletor de contas exibe saldo atual abaixo do nome.
- **Interface — Lancamento:** seletor de cartoes exibe limite disponivel e proximo vencimento.
- **Relatorios — estrutura por workspace:** Personal exibe Fluxo de Caixa e Extrato. Business exibe Fluxo de Caixa, Competencia/DRE e Extrato.
- **Relatorios — Competencia/DRE:** mantida no Business para analise gerencial por data de origem economica, incluindo pagos e pendentes. Compras de cartao entram por competencia; pagamentos de fatura sao excluidos para evitar duplicidade.
- **Relatorios — composicao analitica de cartao:** itens de fatura sao abertos por categoria/macro na analise, evitando agrupar tudo como "Fatura de cartao".

### Corrigido
- **Interface — Lancamento:** vencimento no seletor de cartoes usa `due_date` da proxima fatura `OPEN`.
- **Relatorios — conciliacao:** corrigidas separacao entre caixa realizado, previsao e competencia; duplicidade de faturas; pagamento parcial de fatura; saldo pendente de fatura; percentuais pequenos em categorias; preservacao de tab/modo ao trocar mes.
- **Relatorios — Saldo Projetado:** calculo parte do saldo atual das contas reais, somando pendentes futuros a receber e subtraindo pendentes futuros a pagar e faturas pendentes, sem usar contas de cartao como saldo real.
- **PDFs — acentuacao:** textos como Relatorio, competencia, lancamentos, Transferencias, periodo e Marco agora usam acentuacao correta em todos os PDFs exportados.

## Contrato de instalacao

### Canal stable

```bash
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/install.sh
bash /tmp/contabase-install.sh
```

Enquanto nao houver stable publicada, este fluxo deve abortar com mensagem clara.

### Canal beta

```bash
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/beta/install.sh
bash /tmp/contabase-install.sh
```

### Versao fixa (Docker)

```bash
export CONTABASE_VERSION=v0.1.0-beta.5
export CONTABASE_DATA_DIR=/opt/contabase/data
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/beta/install.sh
bash /tmp/contabase-install.sh
```

### Versao fixa (LXC/VPS — binario)

```bash
export CONTABASE_VERSION=v0.1.0-beta.5
export CONTABASE_INSTALL_DIR=/opt/contabase
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/beta/install.sh
bash /tmp/contabase-install.sh
```

### Imagem Docker

```bash
docker pull ghcr.io/contabase-app/contabase:v0.1.0-beta.5
```

### Atualizacao

```bash
export CONTABASE_VERSION=v0.1.0-beta.5
cd /opt/contabase && bash scripts/update-contabase-docker.sh
```

## Notas tecnicas

- **Fonte PDF embutida:** PDFs agora usam fonte TrueType embutida (Go Regular) em vez de Helvetica Type1 nao-embutida. `pdffonts` mostrara `CBEmbedded-Regular` como fonte embutida.
- **Dependencia nova:** `golang.org/x/image` para parse de TTF e suporte a Unicode nos PDFs.
- **Largura de tabelas:** colunas dos PDFs foram ajustadas para preencher a largura util da pagina, eliminando espaco vazio a direita.
- **CSV:** exportacoes CSV para Caixa, Competencia/DRE e Extrato seguem as mesmas regras financeiras dos PDFs.

## Limitacoes conhecidas

- Stable ainda nao publicada. A versao recomendada e a ultima beta.
- Instalacao publica aponta para `get-contabase.pages.dev`. O dominio `get.contabase.net` ainda nao esta ativo.
- Backup antes de atualizar ambientes com dados reais continua obrigatorio.
