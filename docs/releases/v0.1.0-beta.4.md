# ContaBase v0.1.0-beta.4 - Beta publica controlada

> **Status:** Em preparacao; ainda nao publicada
>
> **Estagio:** Beta publica controlada, nao stable

## Principais mudancas desde v0.1.0-beta.3

### Adicionado
- **Pagamento/recebimento agendado:** transacoes INCOME/EXPENSE pendentes agora podem ser agendadas com data futura. Transferencias, faturas e compras de cartão continuam fora desse fluxo.
- **Executor automático:** o servidor inicia o worker de agendamento, que processa itens vencidos com update atômico e registra histórico/notificação.
- **Data efetiva de pagamento (`paid_at`):** pagamentos individuais e em lote passam a registrar a data real do pagamento sem alterar competência ou vencimento.
- **Histórico de pagamento:** mudanças de status e data ficam registradas em `transaction_status_history` com usuário, data/hora, valores anterior/novo e origem.
- **Conta padrão para pagamento de fatura:** cada cartão pode apontar para uma conta CHECKING/SAVINGS padrão, usada como pré-seleção no modal de quitação.

### Alterado
- **Lançamentos:** faturas seguem os filtros da tela, as parciais exibem o saldo pendente como valor principal e o controle `Selecionar` ficou abaixo dos cartões/faturas.
- **Lançamentos:** o modal de pagamento usa `Pagar agora` e `Agendar`/`Agendar pagamento`, deixando o fluxo mais claro.
- **Lançamentos:** o filtro `Agendado` separa agendados de pendentes e vencidos.
- **Lançamentos:** faturas pagas ficam ocultas por padrão na carga inicial; o filtro `Pago` explícito as revela.
- **Timezone financeiro:** `CONTABASE_TIMEZONE` passa a ser preenchido pelos scripts de install/update quando ausente, preservando valor já configurado.
- **Scripts de install/update:** Docker e release/binário receberam backfill de timezone e seguem a política atual de secrets de update.

### Corrigido
- **Hotfix do `cb-update`:** instalações existentes não exigem mais `CONTABASE_SETUP_TOKEN` para update.
- **Hotfix do update Docker:** a validação de `.env.docker` deixa de tratar `CONTABASE_SETUP_TOKEN` como secret persistente obrigatório.
- **Mensagens de update:** erros de secret passam a focar nos segredos realmente persistentes.
- **Contas a pagar:** `/contas`, aba A Pagar, agora inclui faturas de cartão OPEN/CLOSED com saldo pendente.
- **Contas a pagar:** faturas pagas ou com saldo zero não aparecem como pendência.
- **Contas a pagar:** compras vinculadas e pagamentos de fatura não duplicam em A Pagar.
- **Contas a pagar:** A Receber continua sem faturas de cartão.
- **Lançamentos:** o estado visual de faturas parciais, agendadas e pagas foi ajustado para refletir a regra financeira atual.

## Contrato de instalacao

### Canal stable

```bash
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/install.sh
bash /tmp/contabase-install.sh
```

Enquanto nao houver stable publicada, este fluxo deve abortar com mensagem clara.

### Canal beta

```bash
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/beta/install.sh
bash /tmp/contabase-install.sh
```

Este fluxo instala a versao apontada por `public/channels/beta.json`.

### Versao especifica

```bash
curl -fsSLo /tmp/contabase-install.sh https://get-contabase.pages.dev/install.sh
CONTABASE_VERSION=v0.1.0-beta.4 bash /tmp/contabase-install.sh
```

Instalacoes com `CONTABASE_VERSION` explicito entram em modo `pinned`.

## Atualizacao

```bash
sudo cb-update
sudo cb-update --channel beta
sudo cb-update --channel stable
sudo cb-update v0.1.0-beta.4
```

- `stable` atualiza para a ultima stable publicada.
- `beta` atualiza para a ultima beta publicada.
- `pinned` exige uma versao explicita ou troca explicita de canal.
- beta nunca migra para stable automaticamente.
